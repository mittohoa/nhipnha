Dùng ngay trên trình duyệt

Không cần cài: mở mittohoa.github.io/nhipnha bằng Chrome hoặc Safari, trên điện thoại hay máy tính. Dùng cùng tài khoản với ứng dụng.

Điện thoại Android

Bản Android phát hành qua Google Play. Nếu chưa tìm thấy "Nhịp Nhà" trên cửa hàng thì ứng dụng còn đang trong giai đoạn thử nghiệm — trong lúc đó hãy dùng bản trên trình duyệt.

Máy tính Windows (10 / 11, 64-bit)

Tải NhipNha-windows-x64.zip

  1. Giải nén file vừa tải (bấm phải › Extract All).
  2. Mở thư mục vừa giải nén, chạy NhipNha.exe.
  3. Lần đầu Windows có thể hiện "Windows protected your PC" vì bản này chưa được ký số: chọn More info › Run anyway.

Máy tính Linux (64-bit)

Tải NhipNha-linux-x64.tar.gz

  1. Giải nén: tar -xzf NhipNha-linux-x64.tar.gz -C nhipnha (tạo thư mục nhipnha trước).
  2. Chạy: ./nhipnha/nhipnha.

iPhone, iPad, Mac

Chưa có ứng dụng riêng. Hãy dùng bản trên trình duyệt (Safari) ở trên.

Bản máy tính là bản thử: một số tính năng chỉ có trên Android (widget màn hình chính, Health Connect, chụp phiếu / sổ để đọc chữ, thông báo từ người nhà). Các bản cũ và ghi chú phát hành: github.com/mittohoa/nhipnha/releases.

Nhịp Nhà không phải thiết bị y tế và không chẩn đoán, điều trị, chữa khỏi hay phòng ngừa bất kỳ bệnh nào. Thông tin chỉ để tham khảo; hãy hỏi ý kiến bác sĩ hoặc nhân viên y tế.

Download Nhịp Nhà

Use it in the browser

Nothing to install: open mittohoa.github.io/nhipnha in Chrome or Safari on a phone or computer. Sign in with the same account as the app.

Android phones

The Android app is distributed through Google Play. If you cannot find "Nhịp Nhà" in the store yet, it is still in testing — use the browser version meanwhile.

Windows (10 / 11, 64-bit)

Download NhipNha-windows-x64.zip

  1. Unzip the file (right-click › Extract All).
  2. Open the extracted folder and run NhipNha.exe.
  3. The first time, Windows may show "Windows protected your PC" because this build is not code-signed: choose More info › Run anyway.

Linux (64-bit)

Download NhipNha-linux-x64.tar.gz

  1. Extract: tar -xzf NhipNha-linux-x64.tar.gz -C nhipnha (create the nhipnha folder first).
  2. Run: ./nhipnha/nhipnha.

iPhone, iPad, Mac

There is no native app yet. Use the browser version (Safari) above.

The desktop builds are previews: some features are Android-only (home-screen widgets, Health Connect, reading slips and booklets from photos, family notifications). Older builds and release notes: github.com/mittohoa/nhipnha/releases.
