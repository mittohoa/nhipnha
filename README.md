# Nhịp Nhà — trang công khai

Repo này chỉ chứa **bản web đã build** và các trang công khai của ứng dụng Nhịp Nhà
(theo dõi sức khỏe gia đình). Mã nguồn nằm ở repo riêng tư; nội dung ở đây được sinh tự động
bằng script deploy — đừng sửa trực tiếp.

- Ứng dụng web: https://mittohoa.github.io/nhipnha/
- Chính sách quyền riêng tư: https://mittohoa.github.io/nhipnha/privacy/
- Xóa tài khoản: https://mittohoa.github.io/nhipnha/delete-account/

Góp ý / yêu cầu: [Issues](https://github.com/mittohoa/nhipnha/issues) — đây là trang công khai,
**đừng đăng email hay thông tin sức khỏe**.
